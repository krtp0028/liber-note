# Example Vault

A small vault that demonstrates Liber's features. Open this folder in the app.

- [[Welcome]] — what to look at first
- Projects/Alpha — a branch note with inherited tags and rollups
- Reference/Postgres — appears in two tree places via `also_under`
- Journal/2026-09-16 — daily notes with tasks and wiki links

Tip: check the rollup badges (`0/2 ✓`) on **Projects/Alpha**, and use **Filter tree by tag** with `project-alpha`.

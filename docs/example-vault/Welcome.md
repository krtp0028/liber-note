# Welcome

This vault is a playground for Liber's tree features. Try these:

1. Look at the tree: `Projects/Alpha` has a task badge that sums its whole subtree.
2. `Reference/Postgres.md` lives in `Reference/` on disk but also appears under `Topics/` — that is the `also_under` mirror.
3. `loose-note.md` is re-parented into `Projects/Alpha/` virtually; the file has not moved.
4. Type `tag:project-alpha` in **Search vault** (`Ctrl+Shift+F`) — inherited tags match files that never declared them.
5. Drag a note onto another folder to set its `parent`; hold `Alt` while dropping to add a mirror instead.

See [[Postgres]] and [[Kickoff]].
